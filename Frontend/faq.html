1. What is Metal Vision AI?

Metal Vision AI is an industrial surface inspection system that uses deep learning to classify metal surface defects from images.

2. Which deep learning model is used?

The system uses a ResNet50 transfer-learning model implemented using TensorFlow and Keras.

3. How many defect classes are supported?

The classifier supports 10 defect categories: Punching Hole, Welding Line, Crescent Gap, Water Spot, Oil Spot, Silk Spot, Inclusion, Rolled Pit, Crease and Waist Folding.

4. What is Grad-CAM?

Grad-CAM is a visualization technique that highlights image regions that contributed strongly to the model's prediction.

5. Does Grad-CAM provide exact defect boundaries?

No. In this project Grad-CAM provides approximate defect-region localization. Exact bounding boxes require suitable annotations and a detection or segmentation model.

6. What image size does the model use?

Images are resized to 224 × 224 pixels before model inference.

7. How large is the dataset?

The project dataset contains 2,541 images across 10 defect classes with a 70% training and 30% testing split.

8. Can the current model identify a GOOD surface?

The current classifier was trained only on the 10 defect classes. Therefore it should not be treated as a genuine GOOD/NORMAL detector.

9. Can an inspection report be generated?

Yes. A completed inspection can be exported as a PDF report from the result page.

10. Which backend technology is used?

The backend uses Python and FastAPI, while the frontend uses HTML, CSS and JavaScript.
